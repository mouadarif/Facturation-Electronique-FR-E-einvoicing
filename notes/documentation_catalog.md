# Documentation Catalog

This catalog tracks the local documentation pack by path, category, scope, file type, size, page count when available, and content definition.

## Scope Legend

- `generic_official`: official DGFiP, AIFE, Bercy or similar reusable documents.
- `generic_normative`: AFNOR / normative documents reusable across companies.
- `generic_use_cases`: generic app use-case card data.
- `generic_local_synthesis`: local Markdown synthesis that remains generic.
- `specific_company`: COMEXA/Cegos/company-context material, separated from generic content.
- `index_catalog`: inventories, manifests, source lists and catalogs.
