# Notions par cas de réforme

Date de vérification : 2026-04-26.

Ce document complète `02_DEFINITIONS_NOTIONS_REFORME.md`. Il ne définit pas seulement les notions générales ; il explique la notion portée par chaque cas de l'application, avec le rattachement juridique ou normatif principal.

## Comment lire ce document

- **Notion métier** : ce que le cas signifie dans la pratique.
- **Référence juridique** : texte officiel à consulter pour le périmètre, l'obligation ou la définition fiscale.
- **Référence AFNOR** : norme ou fiche qui explique le traitement opérationnel.
- **Attention** : les cas AFNOR ne remplacent pas le CGI, le BOFiP ou les textes administratifs.
