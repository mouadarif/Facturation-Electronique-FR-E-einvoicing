# D365 F&O — outils et chemins utiles

## Ce que Microsoft documente pour la France
- configuration spécifique France dans **Dynamics 365 Finance / Supply Chain Management**
- usage du service **Electronic invoicing**
- usage de **Globalization Studio**
- import des fonctionnalités depuis le **Dataverse repository**
- usage de **Electronic reporting (ER)** pour le modèle, mapping et formats
